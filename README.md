# 🕴️ MORDOMO — The Gentleman

> Organização, planejamento e clareza para uma vida financeira mais consciente.

O **MORDOMO** é uma aplicação web de gestão financeira pessoal, desenvolvida com foco em **simplicidade, elegância, organização e autonomia**.

O sistema permite acompanhar receitas, despesas, planejamento, dívidas, pagamentos, contribuições e relatórios financeiros.

### 🧠 Conceito

**O MORDOMO organiza. O usuário decide.**

### 🛠️ Tecnologias

- React
- TypeScript
- TanStack Start
- Vite
- Tailwind CSS
- Recharts
- LocalStorage

### 🚀 Executar localmente

```bash
npm install
npm run dev
```

### 🌐 Produção

O projeto utiliza **GitHub + Cloudflare** para integração e deploy contínuo.
